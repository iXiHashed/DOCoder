# DOCoder
**DOCoder** — это простая программа на Python, которая позволяет **шифровать и дешифровать файлы** с использованием симметричного шифрования AES.

---

## 📋 Описание

Программа позволяет:
- Генерировать безопасный ключ шифрования.
- Шифровать файлы любого типа (`.txt`, `.jpg`, `.pdf`, `.mp3`, `.zip` и т.д.), а также папки.
- Дешифровать зашифрованные файлы и папки обратно.
- Работать через удобное текстовое меню терминала и GUI для выбора объекта шифрования или расшифрования.

---

## ✨ Особенности

- Используется **AES-256** — один из самых надёжных алгоритмов шифрования.
- Поддержка **любых типов файлов** (бинарные и текстовые).
- **Модульная структура** — код разделён на логические файлы.
- Простота в использовании — интерактивное меню.
- Безопасное хранение ключа (в отдельном файле).
